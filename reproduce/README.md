## Reproduction Guide

This folder contains scripts and notebooks to reproduce the paper’s analyses and figures using trained model weights. If you haven’t trained a model yet, see the root README’s “Train a model from scratch” section first.

### Folder layout (this directory)

- `datasets/` — Static CSVs used for reproduction (e.g., WFE and SSP datasets). Do not edit in place.
- `data/` — Intermediate caches generated by scripts (CSV/NPY). Safe to delete; use `--regenerate` to rebuild.
- `figures/` — Reproduced figures saved here by the scripts.
- `weights/` — Optional reference weights for quick runs. You can also point scripts to your own trained weights in the repo’s top-level `weights/` directory.
- `scripts/` — Modular analysis scripts (behavioral analyses, embeddings, ablations, univariate feature importance, and a master runner).
- `reproduce.ipynb` — End-to-end notebook version of the reproduction pipeline.
- `paper.ipynb` — Paper-oriented narrative/figures (optional, may mirror sections of `reproduce.ipynb`).

### Environment

Use the repository root environment. From the root:

```bash
pip install -r requirements.txt
python -m spacy download en_core_web_lg
```

### How to run (scripts)

You can run all analyses or pick a specific one. Commands below assume the repository root as the working directory.

Run everything (master script)

```bash
cd reproduce/scripts
python run_all.py
```

Run a specific analysis

- Behavioral (Figure 2A–D):

  ```bash
  cd reproduce/scripts
  python behavioral_analysis.py \
     --model_name Ua_LSTM_h128_l1_v42_d0.0_t0.0_s1 \
     --weights_path weights/2048_75.pth \
     --batch_size 2048
  ```

- Phoneme embeddings + feature importances (Figure 3):

  ```bash
  cd reproduce/scripts
  python phoneme_analysis.py \
     --model_name Ua_LSTM_h128_l1_v42_d0.0_t0.0_s1 \
     --weights_path weights/1024_75.pth \
     --batch_size 1024
  ```

- Ablations (Figure 4):

  ```bash
  cd reproduce/scripts
  python ablation_search.py \
     --model_name Ua_LSTM_h128_l1_v42_d0.0_t0.0_s1 \
     --weights_path weights/2048_75.pth \
     --batch_size 2048
  ```

- Univariate feature importance (neurons x features):
  ```bash
  cd reproduce/scripts
  python univariate_analysis.py \
     --model-name Ua_LSTM_h128_l1_v42_d0.0_t0.0_s1 \
     --weights-path weights/1024_75.pth \
     --batch-size 1024 \
     --hidden-size 128
  ```

Notes

- Relative paths resolve from the `reproduce/scripts` directory when you run scripts there.
- If you trained your own model, pass its checkpoint via `--weights-path` (see next section).
- Use `--regenerate` where available to refresh cached intermediates in `data/`.
- Many scripts also accept `--figures-dir` and `--data-dir`; defaults are sensible.

### Using your own trained weights

Most scripts take `--model_name` and `--weights_path`. If you trained a model with the root training scripts, point `--weights_path` to something like:

```
weights/<model_name>/<train_name>/<epoch>.pth
```

Make sure `--model_name` matches how the model was trained. For a full loading example, see the root README (“Load and evaluate trained weights”).

### Outputs

- Figures: saved to `figures/` in this directory (or a subdir if set).
- Caches: intermediate CSV/NPY saved in `data/`.
- Logs: most scripts print concise progress; check the console for status messages.

### How to run (notebooks)

- `reproduce.ipynb` mirrors the script pipeline with cells that load weights, compute embeddings, run feature importance, ablations, and generate the same figures.
  - Run top-to-bottom; cells are grouped by figure/section.
  - If you see path issues, ensure your kernel’s working directory is the repo root or update paths accordingly.

### Tips for reproducibility

- Seeds are set to fixed values in the scripts; results should be stable across runs and platforms given the same environment.
- Prefer running from the repository root. When inside `reproduce/scripts`, pass explicit paths where needed.
- Keep the naming pair (`model_name`, `train_name`) with your checkpoints for full traceability; store them alongside your figures for archival.

### Minimal one-liners

```bash
# Run all analyses
python reproduce/scripts/run_all.py

# Just univariate analysis
python reproduce/scripts/univariate_analysis.py --model-name Ua_LSTM_h128_l1_v42_d0.0_t0.0_s1 --weights-path weights/1024_75.pth

# Behavioral only
python reproduce/scripts/behavioral_analysis.py --model_name Ua_LSTM_h128_l1_v42_d0.0_t0.0_s1 --weights_path weights/2048_75.pth
```
